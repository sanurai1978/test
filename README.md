# 持株会 会員管理マクロ（Excel VBA）

親会社株の持株会をグループ全体で管理するための Excel VBA 業務システムです。
詳細仕様は [`docs/仕様書.md`](docs/仕様書.md) を参照してください。

## セットアップ手順

1. マクロ有効ブック（`.xlsm`）を新規作成する。
2. 以下の9シートを作成し、1行目に `docs/仕様書.md` ■3 シート仕様のとおり
   見出しを入力する。
   - 設定
   - 会社マスタ
   - 株価マスタ
   - イベント入力
   - 会員マスタ
   - 拠出設定
   - イベント履歴
   - 月次実績
   - 操作ログ
   - スナップショット（Step9の出力先として追加）
3. VBE（Alt+F11）で `src/vba/` 配下の `.bas` ファイルを
   「ファイル」→「ファイルのインポート」で以下の順にインポートする。
   1. `01_modConstants.bas`
   2. `02_modCommon.bas`
   3. `03_modEventInput.bas`
   4. `04_modMemberMaster.bas`
   5. `05_modContribution.bas`
   6. `06_modEventHistory.bas`
   7. `07_modMonthlyResults.bas`
   8. `08_modSnapshot.bas`
   9. `09_modMain.bas`
4. 参照設定は不要（`Scripting.Dictionary` は `CreateObject` で生成するため）。
5. 設定シートに `処理対象年月`（例: `202601`）を登録する。
6. 会社マスタ・株価マスタに初期データを登録する。
7. イベント入力シートに会員イベント（入会・退会・休会・休会から復帰・口数変更）を入力する。
8. `modMain.Pr_全処理実行` を実行する（イベント入力反映→月次実績更新→スナップショット出力を順に実行）。
   個別に実行したい場合は `Pr_イベント入力反映` / `Pr_月次実績更新` / `Pr_スナップショット出力` を
   それぞれ実行する。

## 設計方針

- マスタ直接編集禁止（ユーザーはイベント入力シートのみ編集）
- 履歴は物理削除しない（拠出設定・イベント履歴・操作ログは追記/論理更新のみ）
- 何度でも安全に再実行できる（処理済スキップ・Upsert・終了済みガードにより担保）
- 列番号はハードコーディングせず、ヘッダー列マップ（Dictionary）経由でのみ参照する

# 生産管理シミュレータ　Excel VBA 版

HTML 版の生産管理シミュレータ（`生産管理シミュレータ.html`）と同じ業務ルールで動く、Excel VBA 版です。
学習用です。会社もデータもすべて架空です。

## いまの段階

| 段階 | 内容 | 状態 |
|---|---|---|
| 1 | 土台：シート構成、初期データ投入、メニュー、採番、在庫一覧 | 済 |
| 2 | 受注登録・見込登録 → MRP 実行 → 製造指図・発注の作成（一括手配） | 未 |
| 3 | ピッキング、払出・着手、工程実績、外注、入荷、完成入庫、出荷、履歴 | 未 |
| 4 | 帳票4種の PDF 出力、レポート3種、BOM照会・工程照会 | 未 |

## ファイル構成

| 場所 | 中身 |
|---|---|
| `vba/*.bas` | **VBE に取り込むファイル**（Shift_JIS・CRLF） |
| `src/*.bas` | 上と同じ中身の編集用の原本（UTF-8）。`tools/build.py` で `vba/` を作る |
| `tools/build.py` | `src/` → `vba/` の変換。Shift_JIS にできない文字があれば止まる |
| `tools/lint.py` | VBA の書き方の機械点検（接頭辞、Call、目次型メイン、呼び出し行のコメント） |
| `test/` | 自動テスト（LibreOffice で VBA を動かし、HTML 版の数字と突き合わせる） |

## 取り込み手順（初回だけ）

1. Excel で空のブックを作り、「名前を付けて保存」で **Excel マクロ有効ブック（*.xlsm）** にします。
2. Alt+F11 で VBE を開き、「ファイル」→「ファイルのインポート」で `vba/` の `.bas` を**全部**取り込みます（順番は自由です）。
3. 参照設定は要りません（Dictionary は `CreateObject` で作ります）。
4. Excel に戻り、Alt+F8 で `Pr_初期化` を実行します。シート・ボタン・初期データがすべてできます。
5. 上書き保存します。2回目からは、メニューの「初期データに戻す」で同じ初期化ができます。

※ 既存のブックで `Pr_初期化` を実行すると、**そのブックのシートはすべて消えて作り直されます**（確認が出ます）。

## 段階1のテスト手順（Excel で行う）

正しい結果は、HTML 版で「初期データに戻す」をした直後の画面と同じ数字です。

   → 「初期データを入れました」と出て、メニューが開きます。シートは18枚です（メニュー、在庫一覧、品目〜設定）。

9. **初期データに戻す**：押すと確認が出る。「いいえ」なら何も変わらない。

## 自動テスト（開発用）

この環境には Excel が無いため、LibreOffice の VBA 互換モードで `src/` のマクロを実際に動かし、
HTML 版（Playwright で操作）の数字と突き合わせています。

```
python3 tools/lint.py
python3 tools/build.py
/usr/bin/python3 test/test_stage1.py <生産管理シミュレータ.html のパス>
```

LibreOffice に無い部品は、テストのときだけメモリ上で置き換えています（`vba/` のファイルは変えません）。

- `Scripting.Dictionary` → テスト用の `Cs_辞書`
- `MsgBox` → 画面を出さずに記録する
- フォームのボタン作成、シート見出しの色 → 省略

このため、**ボタンの作成・押したボタンからの移動先の判定（`Application.Caller`）・シート見出しの色は Excel で未確認**です。
